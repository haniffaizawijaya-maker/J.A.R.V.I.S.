# J.A.R.V.I.S. 3.0 // MK-LVII Command Center

An autonomous, multi-lingual desktop AI assistant for Windows inspired by Iron Man's J.A.R.V.I.S. and FatihMakes' Mark-LVII Command Center.

## Features
- **Sci-Fi 3-Column Hologram Command Center**: Realtime hardware telemetry, rotating concentric arc reactor HUD, and communications transcript log.
- **Biometric Voice Authorization**: Locks access exclusively to Master Hanif, rejecting unknown voices.
- **Ultra-Realistic Neural Voice**: English British Butler (RyanNeural) & Multilingual Paul Bettany tone.
- **Windows Control**: Launch and close apps/games (Spotify, Chrome, Fortnite, VALORANT, etc.).
- **Long-Term Persistent Memory**: Remembers instructions, notes, and user preferences.
- **Windows Startup Auto-Welcome**: Greet Master Hanif upon PC power-on.
- **Live Environmental & Weather Reports**: Real-time atmospheric briefings.
